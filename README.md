# Smart Blind Stick - Obstacle Detection System

An Arduino-powered assistive navigation device designed to help visually impaired individuals detect obstacles safely through real-time audio and visual alerts[cite: 3].

## 🚀 Features
* **Ultrasonic Sensing:** Continuously monitors obstacles in the user's path using the HC-SR04 sensor[cite: 3].
* **Audio-Visual Feedback:** Triggers a buzzer and an LED indicator when an object is detected within the safety threshold range[cite: 3].
* **Microcontroller Unit:** Controlled via an Arduino Uno running embedded C/C++ logic[cite: 3].

## 🛠️ Hardware Components
* Arduino Uno[cite: 3]
* HC-SR04 Ultrasonic Sensor[cite: 3]
* Piezo Buzzer (3V - 5V)[cite: 3]
* Red LED Indicator[cite: 3]
* 5V Rechargeable Battery / Power Supply[cite: 3]
* Jumper wires & Breadboard / PCB[cite: 3]

## 💻 Software & Tools
* **Arduino IDE** (Written in C/C++)[cite: 3]
* **Proteus / Tinkercad** (For circuit simulation and testing)[cite: 3]
